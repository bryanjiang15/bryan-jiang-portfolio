# Bryan Jiang — Portfolio

Cinematic music-themed portfolio (About draft).

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4
- GSAP + ScrollTrigger
- Motion

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

The mock Design Canvas export lives in `Music-themed SWE portfolio/` as reference only.
